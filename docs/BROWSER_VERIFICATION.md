# 社区浏览增强验证

2026-11-14，在独立工作区基于已合并主分支实现。按正文数据、社区发现、分页与上下文、媒体、作者收藏、观察快照的顺序提交。

## 本地行为

`python -m unittest discover -s tests -q` 覆盖原有发送合同及浏览功能，包括正文缺失与无全文证据、图文顺序、未知块、帖子链接、社区分类、条目筛选、真实搜索列表结构、三态分页、预算、账号与查询绑定续读、重复节点、后续页错误、祖先链、图片摘要缓存、GIF 首帧、作者身份、收藏夹、观察差异和跨进程续读。

`python tests/verify_portable.py` 复制全部脚本与测试到无关目录。核心帮助、账号帮助和 Web offline doctor 使用 `-I -S`，不依赖原 checkout 或 site-packages；媒体测试在安装 Pillow 的环境执行。21 个 SDK 文件摘要保持与原快照一致。

skill-creator 的 `quick_validate.py` 验证技能结构。核心运行没有增加 Python 依赖，媒体预览按需安装 `requirements-media.txt`。

## 真实只读检查

使用隔离测试账号 `xhh-test-web`，在线身份检查返回 `session_valid=true` 和 `api_identity_verified=true`。没有向小黑盒点赞、评论、发布、删除或修改账号配置。

- 社区分类返回 71 个社区条目；社区名称搜索、详情、子分类调用成功。所测社区的子分类为空，结束范围保持未知。
- 话题搜索和热点读取均返回 20 条；信息流返回 19 条，工具如实报告服务器实际返回数量。
- 动态正文、独立评论和根楼层上下文可读取，范围与更多页状态保留。
- 作者公开资料和作者帖子可读取，并核对返回作者 UID；过滤编辑器和草稿字段。
- 测试账号收藏夹查询成功，但返回为空。真实收藏内容的读取效果没有用该空账号证明；其接口合同和分页由模拟响应测试覆盖。
- 游戏搜索返回 2 条。帖子搜索所用词返回空 `items`，保留平台筛选信息，不能据此断言全站没有内容。
- 命名评论快照能继续下一页，保存新的断点。跨页重复节点由行为测试验证并保留完整观察集。
- 图片下载和本地 PNG 预览成功，源与预览摘要可核对。
- 同一长文章在 native 方式返回正文缺失，在显式 website 方式返回可用的 9 个正文块。平台没有明确全文标记，完整性仍为 `unknown`。

网站方式的只读测试发现缺失 `x_os_type`，已补充该协议字段，并验证单次失败不触发 fallback。真实返回仅用于本地验证，原始公开文本和测试账号数据不提交到仓库。

## 范围

API 接受、正文可用、读取范围与公开效果分开。非空正文不能证明完整全文，空列表不能证明全量历史结束，未再次观察到的条目不推断删除。整个增强不读取宿主人格、情绪、私聊、记忆或调度状态。

独立代理审阅尚未完成，不以本地测试或 CI 替代该审阅。
